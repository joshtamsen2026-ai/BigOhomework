# Big O Detective - Performance Analysis Project

## Overview

This project analyzes the time complexity of several Python functions and demonstrates the performance difference between two approaches for solving the pair-sum problem:

- **O(n²)** implementation using nested loops
- **O(n)** implementation using a dictionary/hash map

The program benchmarks both algorithms using lists of increasing sizes and generates detailed performance reports in CSV format.

---

## Requirements

- Python 3.8 or newer
- No third-party libraries required

The project only uses Python standard library modules:

- `time`
- `random`
- `csv`
- `os`
- `platform`
- `subprocess`
- `datetime`

## Running the Program

### Windows

Open Command Prompt in the project directory and run:

```bash
python big_o_detective.py
```

### macOS / Linux

Open a terminal in the project directory and run:

```bash
python3 big_o_detective.py
```

---

## What Happens When the Program Runs

1. The program benchmarks both pair-counting algorithms.
2. Tests are performed using list sizes:
   - 1,000 elements
   - 5,000 elements
   - 10,000 elements
3. Runtime measurements are collected using `time.perf_counter()`.
4. Speedup values are calculated.
5. Two CSV reports are generated.
6. The CSV files are automatically opened (if supported by the operating system).

## Expected Results

As the input size increases:

- The O(n²) algorithm becomes dramatically slower.
- The O(n) algorithm scales efficiently.
- The speedup factor grows significantly for larger datasets.

This demonstrates why selecting efficient algorithms becomes increasingly important when working with large amounts of data.
